# 招聘邮箱工作手册

## 概述

hr@quanttide.com 是量潮科技招聘专用公共邮箱，采用**标签即流程状态**的方式管理候选人的招聘全流程。每封邮件对应一个候选人，通过标签标记其所处的招聘阶段。

## 标签体系

### 完整标签清单

| 标签 | 颜色 | 含义 |
|------|------|------|
| `川艺` | carmine（红） | 特定合作渠道 |
| `笔试阶段` | blue（蓝） | 笔试阶段整体 |
| `笔试阶段/笔试已发送` | blue | 笔试已发出，等待候选人作答 |
| `笔试阶段/笔试中` | blue | 候选人正在作答 |
| `笔试阶段/笔试未通过` | blue | 笔试未通过 |
| `笔试阶段/第二次机会` | blue | 给予二次笔试机会 |
| `面试阶段` | yellow（黄） | 面试阶段整体 |
| `面试阶段/待面试` | yellow | 等待安排或进行面试 |
| `面试阶段/备选` | yellow | 作为备选候选人 |
| `淘汰阶段` | wathet（浅蓝） | 淘汰阶段整体 |
| `淘汰阶段/初筛淘汰` | wathet | 简历初筛未通过 |
| `淘汰阶段/笔试淘汰` | wathet | 笔试阶段淘汰 |
| `淘汰阶段/面试淘汰` | wathet | 面试阶段淘汰 |
| `待确认状态` | violet（紫） | 流程卡住待人工处理 |
| `待确认状态/笔试通过无后续` | violet | 笔试通过但无后续动作 |
| `待确认状态/面试通过无后续` | violet | 面试通过但无后续动作 |
| `咨询` | carmine（红） | 咨询业务线招聘 |
| `咨询/咨询岗位` | carmine | 咨询岗位相关招聘 |
| `笔试级别` | yellow（黄） | 笔试评级（交叉维度） |
| `笔试级别/S` | red（红） | S 级（优秀） |
| `笔试级别/A` | yellow（黄） | A 级（良好） |
| `笔试级别/C` | lime（绿） | C 级（通过/基础） |

### 颜色约定

标签颜色直观反映阶段性质：

| 颜色 | 含义 |
|------|------|
| 🔵 blue | 进行中的阶段（笔试阶段） |
| 🟡 yellow | 等待/评估状态（面试阶段、笔试级别） |
| 🔴 carmine/red | 特殊渠道或高分（川艺、咨询、笔试S级） |
| 🟣 violet | 待人工跟进 |
| 🔷 wathet | 终结/淘汰 |
| 🟢 lime/green | 通过类状态 |

## 招聘工作流程

### 主线流程

```
投递邮件 → hr@quanttide.com
    │
    ▼
┌─ 初筛 ──────────────────────────────┐
│  ├ 通过 → 进入笔试阶段               │
│  └ 淘汰 → 打标签「淘汰阶段/初筛淘汰」 │
└──────────────────────────────────────┘
    │
    ▼
┌─ 笔试阶段 ────────────────────────────────────────────┐
│  ├ 发送笔试题目 → 打标签「笔试阶段/笔试已发送」          │
│  ├ 候选人作答中 → 更新为「笔试阶段/笔试中」             │
│  ├ 通过 → 打标签「笔试级别/{S|A|C}」，进入面试阶段      │
│  │     └ 无后续动作 → 加「待确认状态/笔试通过无后续」    │
│  ├ 第二次机会 → 打标签「笔试阶段/第二次机会」            │
│  └ 未通过 → 打标签「淘汰阶段/笔试淘汰」                 │
└────────────────────────────────────────────────────────┘
    │
    ▼
┌─ 面试阶段 ────────────────────────────────────────────┐
│  ├ 安排面试 → 打标签「面试阶段/待面试」                  │
│  ├ 通过 → 推进录用流程                                 │
│  │     └ 无后续动作 → 加「待确认状态/面试通过无后续」    │
│  ├ 备选 → 打标签「面试阶段/备选」                       │
│  └ 淘汰 → 打标签「淘汰阶段/面试淘汰」                   │
└────────────────────────────────────────────────────────┘
```

### 交叉维度：笔试级别

笔试级别独立于阶段标签，用于标记笔试成绩质量，可与其他阶段标签共存：

- `笔试级别/S` — 优秀（标记红色，突出显示）
- `笔试级别/A` — 良好
- `笔试级别/C` — 通过/基础

例如，一个候选人可以同时带有 `笔试阶段/笔试通过无后续` 和 `笔试级别/S` 标签。

### 特殊分支

| 分支 | 说明 |
|------|------|
| **川艺** | 独立于主流程的特定合作招聘渠道 |
| **咨询/咨询岗位** | 咨询业务线的专项招聘，独立打标 |
| **待确认状态** | 流程卡住的候选人，需定期人工 review 决定推进或淘汰 |

## 邮件标签操作规范

### 标签管理工具

通过飞书邮箱的标签功能进行管理，操作命令：

```bash
# 列出 hr 邮箱全部标签
lark-cli mail user_mailbox.labels list \
  --params '{"user_mailbox_id":"hr@quanttide.com"}'

# 为邮件添加标签
lark-cli mail user_mailbox.messages modify \
  --params '{"user_mailbox_id":"hr@quanttide.com","message_id":"<id>"}' \
  --data '{"add_label_ids":["<label_id>"]}'

# 为邮件移除标签
lark-cli mail user_mailbox.messages modify \
  --params '{"user_mailbox_id":"hr@quanttide.com","message_id":"<id>"}' \
  --data '{"remove_label_ids":["<label_id>"]}'
```

### 操作原则

1. **一邮件一候选人**：每封候选人邮件独立管理，不要混在同一会话中
2. **阶段递进**：候选人进入下一阶段时，替换上一阶段的阶段标签（而非叠加），笔试级别等交叉标签保留
3. **及时清除**：候选人进入淘汰阶段后，移除一切进行中/待确认阶段的标签
4. **定期清理待确认**：建议每周 review 一次 `待确认状态` 的邮件，决定推进或淘汰
