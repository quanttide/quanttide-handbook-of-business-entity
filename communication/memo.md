# 沟通管理工作手册

## 沟通渠道与平台

| 渠道 | 用途 |
|---|---|
| 消息 | 日常协同、快速确认 |
| 邮件 | 正式沟通、外部对接 |
| 会议 | 复杂讨论、决策对齐 |

**沟通流程：** 外部 → 内部 → 外部（信息从外部流入，内部消化后，再输出到外部）。

## 基于备忘的沟通

核心思想：用标准化的"接口"降低沟通成本。即使人不在现场，团队也能通过清晰的备忘指令自动协同，完成复杂任务。

### 角色分工

| 角色 | 职责 | 核心要求 |
|---|---|---|
| **发送者**（顶层设计师） | 拆分任务模块，明确产出指标与执行框架 | 负责设计与担责。执行路径不明确由发送者背锅 |
| **接收者**（执行层） | 按备忘指令落地执行 | 非重要过程细节需上级决策由执行者负责 |

上下游能否流畅协作，关键在于多模块产出点能否快速流转使用——需要大量二次加工的模块产出视为不合格。

### 五大原则

#### 原则一：指令具象化

拒绝模糊，把"意图"翻译成"动作"。

- **误区：** "你去负责一下招生。"（太模糊，无法执行）
- **正解：** "你去让商务收集一下工作组的想法，整理成结论发给梓姗。"（具体动作）
- **方法：** 发出备忘前先问自己——**"我希望对方收到信息后，做的第一件事是什么？"** 把这个动作清晰地写出来。

#### 原则二：角色剧本化

明确"你是谁"和"你要做什么"。

- **误区：** 让新商务自己去"悟"该干什么。
- **正解：** 在备忘中直接定义角色关系——"你（商务）是收集者"、"梓姗是接收者和决策者"。
- **方法：** 用**"主语+谓语+宾语"**的结构明确责任归属。每个人接到备忘时就像演员拿到剧本，知道自己该在哪一场戏里做什么。

#### 原则三：流程节点化

把"流程"拆解为可追踪的"节点"。

- **误区：** "你去跟进一下这个项目。"（没有终点，无法追踪）
- **正解：** "收集想法 → 整理结论 → 发给梓姗。"（三个清晰的节点）
- **方法：** 一份优秀的备忘应该是一张**"路线图"**——标明起点（谁发起）、路径（经过谁）、终点（给谁收）。你只需要在终点检查结果，而不需要在路上催促过程。

#### 原则四：反馈闭环化

确保信息有发出就有回响。

- **误区：** "大家看着办，有结果告诉我。"（被动等待）
- **正解：** "结论发给梓姗收。"（明确的反馈路径）
- **方法：** 每一个备忘都应该是一个**"闭环"**——要么是"执行→汇报"，要么是"建议→决策"。明确规定执行后的信息流向哪里，由谁来确认。

#### 原则五：意图分层化

区分"愿景"、"策略"和"执行"。

- **误区：** 把所有想法一股脑倒给执行层，造成信息过载。
- **正解：**
  - 给管理层：讲愿景、讲策略、讲意图
  - 给执行层：讲动作、讲步骤、讲标准
- **方法：** 最高指挥者看到的是"森林"（愿景），但给执行者发的备忘只能是"一棵具体的树"（任务）。不要让执行者去解读战略意图，直接告诉他们战术动作。

### AI 辅助流程

**消息 → 便签 → 备忘**

1. 人输入原始信息，AI 输出结构化内容
2. 复制有用的信息到备忘录；如果没有就只复制自己的输入，思考后二次输入
3. 重复循环，直到备忘录积累一堆碎片
4. 把碎片丢给 AI 整理成一份能读的备忘

产出清晰的备忘录，可作为议题底稿、文档底稿，或直接用于沟通。

> 设计者注：沟通成本是组织规模扩大后最隐蔽的损耗。两个人的团队靠默契就够了，二十个人的团队就必须靠"接口"。备忘不是官僚主义的 paperwork，它是你给团队发的"软件包"——参数清晰、接口明确、开箱即用。五大原则的核心只有一句话：**不要让接收者猜测你的意图。**

## 附录：备忘质量检查清单

- [ ] 指令是否具象化？对方知道第一件事做什么吗？
- [ ] 角色是否明确？每个人知道自己的职责吗？
- [ ] 流程是否有节点？可以追踪进度吗？
- [ ] 反馈是否闭环？信息发出后流向哪里？
- [ ] 意图是否分层？管理层和执行层的信息区分了吗？

## 手册使用建议

1. 每次发出备忘前，对照五大原则检查一遍。
2. 积累优秀的备忘案例，作为团队培训素材。
3. 手册不替代章程：正式沟通制度以章程为准。
