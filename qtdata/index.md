# 量潮数据

本板块记录量潮数据相关的商务拓展和项目交付流程。

## 流程概览

量潮数据的完整业务流从线索到交付分为五个环节：

```
线索获取 → 需求评估 → 报价签约 → 执行交付 → 收尾归档
```

每个环节的详细操作见对应文档。

## 一、线索获取

当前主渠道为小红书。日常刷推荐流时留意软件、数据、算法类需求帖子，也可针对性搜索关键词辅助。

初步判断时先检查账号——老号信用度更高，对新号需求保持谨慎，通过帖子内容和用户历史笔记验证需求真实性。确认是真需求后，先在帖子下评论留言引导私信，再通过私信将客户引入微信深度沟通。

## 二、需求评估

与客户沟通时逐项确认以下核心要素：

- **数据源**：目标网站或平台的URL
- **交付成果**：数据集还是代码，必须确认
- **字段需求**：逐项确认，字段变更可能影响工期和报价
- **数据量级**：预估总量，作为报价基础
- **合规性**：数据用途是否合规
- **反爬难度**：初步评估目标网站的反爬虫机制强弱

确认后进入报价流程，详见[商务拓展](./business.md)。

## 三、报价签约

根据服务类型、数据量级、难度等级等因素定价。量潮数据采用难易程度定价与数据标注特殊定价两套体系，同时支持加急项目溢价。

报价时使用公式化报价，让客户清楚价格构成。明确告知客户需求变更时将根据公式重新调整价格，风险透明。

签约时需明确收款比例（首付30-50%、中期30-40%、尾款20-30%）、交付约定和需求变更原则。

详细定价规则和报价单模板见[商务拓展](./business.md)。

## 四、执行交付

项目签订后按标准作业程序执行，分为六个阶段：

1. **需求阶段**：撰写策划书，客户确认后找技术评估工时
2. **报价阶段**：出报价单，客户接受则进入合同流程；不接受则提供降本方案
3. **合同与启动**：合同盖章 → 首款到账 → 通知技术开工
4. **开发与跟进**：每周确认技术进度，定期向客户同步
5. **交付与验收**：通过邮件正式交付，附带保存期限提示，客户确认后催尾款
6. **收尾**：归档全部项目文档，撰写项目复盘

每个阶段的话术模板、交付邮件模板和项目交接文档模板见[项目管理](./project.md)。

## 五、内部协作分工

量潮数据项目涉及以下角色：

- **销售**：主动寻找线索，建立初步信任。要求外向、善于沟通。
- **商务经理**：深度需求沟通、定价、谈判和签单。要求逻辑性强、精通谈判。
- **技术评估员**：协助评估技术难度和反爬虫强度。初期可由技术成员兼任。
- **项目经理**：进度监控、客户沟通、资源协调。项目多时必须有此角色。
- **实施团队**：数据工程师和数据分析师。核心团队负责评估和复杂项目，常规实施可外包。

## 操作清单

销售或商务人员与客户对接前，逐项确认：

- [ ] 目标网址是否明确
- [ ] 需要爬取哪些具体字段
- [ ] 预计数据量级是多少
- [ ] 交付物是数据集还是代码
- [ ] 客户数据用途是否合规
- [ ] 技术员已初步评估反爬难度
- [ ] 是否已使用公式化报价并向客户说明变更规则
