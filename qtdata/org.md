# 量潮数据岗位职责

## 三类核心岗位

### 项目经理（PM）

**职责：**
1. 作为客户主接口人，统筹工作订单的协商、签署、变更与关闭
2. 组织内部资源，制定实施计划与交付时间表
3. 监控进度与质量，定期向客户同步进展
4. 管理费用结算流程，确认工作量与账单
5. 发生数据安全事件或违约风险时，立即启动内部上报
6. 对交付物进行内部质量审核，确认符合验收标准后放行

**权限：**
- 调动项目所需人员与技术资源
- 审批交付物初稿，在工作订单范围内签署日常通讯文件
- 暂停不符合质量或安全要求的作业，要求返工

### 商务经理

**职责：**
1. 审核工作订单中费用、计价方式、知识产权归属等商务条款
2. 处理与合同相关的争议、索赔、变更协议
3. 就保密义务向项目团队提示，管理对外披露信息的合规性
4. 就违约风险发出预警，代表公司进行协商谈判

**权限：**
- 审核对外签署的订单及补充协议
- 就违约风险发出预警

### 数据工程师

**职责：**
1. 完成数据采集、清洗、脱敏、分析、建模、可视化等具体工作
2. 严格遵守数据源使用限制，仅在授权目的下处理数据
3. 使用正版、安全的技术工具与环境
4. 区分客户原始数据与公司预置工具，防止知识产权混淆
5. 提供完整的技术文档与代码说明
6. 执行数据安全保障措施（加密、脱敏、访问控制等）
7. 服务结束时执行数据返还或彻底删除

**权限：**
- 使用公司授权范围内的软件、算法库及计算资源
- 申请获取必要的客户接口权限和数据样本
- 发现安全隐患时，有权要求暂停相关数据处理活动

## 协作机制

- 每周召开项目例会，三类岗位必须参加，通报进度、风险与问题
- 涉及客户数据范围变更、工具引入等重大事项，须经数据工程师及商务经理双线评估并形成书面记录
- 所有与客户的正式承诺、验收确认、问题回复，统由项目经理归口发出
- 客户联系人由项目经理担任，技术交流可增加数据工程师，但决策性沟通需项目经理在场

## 追责原则

- 客户体验问题 → 项目经理负责
- 执行问题 → 数据工程师负责
- 商务问题 → 商务经理负责
- 不允许模糊归因或集体免责
- 造成公司损失的，有权追偿
