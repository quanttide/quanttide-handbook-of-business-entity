# 新媒体销售

## 角色

主要：
- 销售（前台）：和客户沟通需求和报价。

次要：
- 商务（后台）：提供快速报价方案。

## 目标

完成新客户的获取和初步转化，为商务经理铺路。

## 流程

1. 寻找销售线索。比如“需要xxxx数据”。
2. 私信联系。对于疑惑的问题直接进一步联系，比如说“数据量和数据规模多大”、“工期需求多少”等。
3. 请求商务提供快速报价。
4. 确定客户意向。如果成功则转交给商务经理，如果失败则结束。

## 验收

### 过程检查

- 销售线索：线索记录可查（客户、需求）
- 私信联系：联系记录存在
- 请求报价：已提交商务
- 确定意向：有明确结论（成交/失败）

### 结果质量

核心标准：交接给商务经理的线索是热的还是冷的。

- 热线索：客户已明确需求、认可报价，商务经理直接推进即可
- 冷线索：商务经理还需从头再问一遍

### 最小记录格式

每次线索跟到底时，产出一条记录：

```
线索：xxx公司/个人
需求：xxxx数据
报价：xxx元
结果：成交/失败
交接：已接手 / 无需跟进
```
