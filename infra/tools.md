# 基础设施工作手册

## 推荐工具清单

推荐在团队层面统一的工具，需要重点维护。

### 基础 IDE

| 工具 | 适用场景 |
|---|---|
| PyCharm | 以 Python 为主的项目 |
| VSCode | 多语言开发 |

### Vibe Coding IDE 插件

| 工具 | 说明 |
|---|---|
| GitHub Copilot | 每月有限额 |
| 智谱 CodeGeex | 可用 |

### Vibe Coding 命令行

| 工具 | 说明 |
|---|---|
| Claude Code | 除了 Token 用量大，无其他缺点 |

### DevOps 平台

| 平台 | 说明 |
|---|---|
| GitHub | 主平台，最主流的 Git 托管 |
| GitLink | 备份平台，中国计算机学会下属机构 |

### IaaS 平台

| 平台 | 说明 |
|---|---|
| 阿里云 | 国内主要平台，及格 |
| AWS 全球 | 国外主要平台，及格但较贵 |

## 自由选择清单

因账号注册、安全、费用核算等问题无法在团队层面统一推广，建议团队成员根据需求自行探索：

- Google Antigravity（注册困难）
- Cursor（团队层面推广困难）
- Windsurf（团队层面推广困难）

## 不推荐清单

存在较严重功能性问题：

| 类别 | 工具 | 原因 |
|---|---|---|
| IDE 插件 | 通义灵码 | 可用性较差 |
| DevOps | GitLab 中国版极狐 | 稳定性问题 |
| IaaS | AWS 中国 | 性能问题 |
| IaaS | 腾讯云 | 稳定性问题 |

> 设计者注：工具选型的核心原则是"团队统一优先"。统一工具降低协作成本，但也要给个人探索空间。推荐清单里的工具是团队承诺维护的，自由清单里的工具你可以自己试但不保证有支持。不推荐清单是踩过坑的——不拦着你试，但建议先看看为什么被列进去。

## 手册使用建议

1. 推荐清单由团队共同维护，定期评估更新。
2. 踩坑记录及时补充到不推荐清单的说明中。
3. 手册不替代章程：正式基础设施制度以章程为准。
