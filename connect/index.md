# 沟通管理工作手册

本章提供内外部沟通的操作模板和检查清单。配套制度见章程（`bylaw/connect/index.md`），概念讲解见教程（`tutorial/connect/index.md`）。

## 一般方法

动手写信息前先判断两个问题：

1. **对象是谁？** 内部同事还是外部人员？
2. **说什么？** 日常确认（走消息）、正式决策（走邮件）、还是复杂讨论（走会议）？

判断清楚之后，按对应场景的模板组织信息，发出前对照检查清单过一遍。

## 内部沟通

**核心策略**：精简优先。对方和你在同一个上下文里，不需要从头解释。

**模板**：

```
【背景】（一句话）
【任务】（具体动作）
【附件】（材料链接或路径）
【截止】（时间节点）
【反馈】（结论发给谁）
```

**检查清单**：
- [ ] 背景对方真的知道吗？确认你省略的信息是对方已知的，不是你以为对方已知的
- [ ] 附上材料并指明了查阅位置？不需要在正文里引用全文
- [ ] 写清楚了"XX前回复"还是"自行推进"？不需要多余客套

## 外部沟通

**核心策略**：零理解负担。对方不熟悉你们公司，你承担全部适配责任。

**模板**：

```
【背景】（完整上下文，让对方理解来龙去脉）
【核心事项】（关键信息写在正文，不依赖附件）
【期望行动】（明确希望对方做什么）
【附件】（补充佐证，非必读）
【反馈路径】（指定对接人及渠道）
```

**检查清单**：
- [ ] 没有事实错误？数据、引用、陈述都核实过
- [ ] 没有理解负担？内部术语和缩写都展开了。把"请走 PR 流程"改成"请通过项目评审流程提交需求"
- [ ] 不做多余修饰？删掉"不好意思""可能""建议您"这类稀释语气的词。准确比得体重要
- [ ] 核心结论在正文里，不是在附件里？不要写"详见附件"
- [ ] 预留了合理的反馈时间？外部沟通节奏不同，不要以内部节奏压外部节点
