# 数字资产质量

## 意图

通过质量检查发现和辨别高质量资产和低质量资产，以高质量资产为样本维护低质量资产。

## 流程

### 定义质量维度

- 知识工程：检查文档资产是否可以转化为可编程的知识。
- 叙事工程：检查文档叙事是否友好易懂。
- 认知工程：检查文档是否具备完整的心智模型。如工作手册通常由意图、流程和验收三个部分组成。

### 执行评估

使用 CLI 工具 `qtadmin asset quality` 对手册目录执行评估：

```bash
# 快速评估（仅 index.md）
qtadmin asset quality --quick

# 完整评估所有文件
qtadmin asset quality

# 保存结果到文件
qtadmin asset quality --output results.json --report report.md

# 断点续评（长时间评估中断后继续）
qtadmin asset quality --resume --output results.json
```

### 诊断分级

| 分数 | 等级 | 含义 |
|------|------|------|
| ≥ 4.0 | 🟢 健康 | 可作范本，内容质量好 |
| 2.5–3.9 | 🟡 亚健康 | 基本可用，有改进空间 |
| < 2.5 | 🔴 不健康 | 需要重写或补充 |

## 验收

评估结果应当满足以下条件：

- 所有 index.md 的总体平均分 ≥ 3.0
- 叙事工程维度平均分 ≥ 4.0
- 最差文件已识别并有改进行动计划
- 同一职能的手册之间分数波动不超过 1.5 分
