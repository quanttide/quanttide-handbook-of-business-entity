# 入职操作手册

## 入职流程

```
发 Offer → 入职前准备 → 入职当天 → 入职培训 → 适应期跟进 → 试用期管理 → 转正
```

## 入职前准备

### HR 部门

- 薪资待遇确认与合同签署安排
- 制度规范文档准备
- 团队协作工具账号开通（飞书、邮箱等）
- 交接汇报链条确认

### 所属部门

- 部门职责分工说明文档
- 当前主要工作与项目背景
- 新人的分工安排
- 需要接手的工作清单

## 入职当天

### 手续办理

- 签署劳动合同（纸质或电子）
- 提交身份证明、学历证明等入职材料
- 填写个人信息登记表
- 办理工资卡登记
- 领取办公设备（电脑、钥匙、门禁卡等）

### 系统与环境

- 开通飞书账号，加入公司组织架构
- 开通企业邮箱
- 加入相关群组与频道
- 配置代码仓库、文档平台等工具访问权限
- 确认开发环境搭建指引

### 团队介绍

- 由直属上级带领认识团队成员
- 介绍团队协作方式（周会、日报、异步协作等）
- 明确对接人：HR 对接人、技术导师、直接上级
- 加入团队日历与项目看板

## 入职培训

### HR 部门负责

- 薪资待遇说明
- 制度规范宣导
- 团队协作格式培训
- 交接汇报链条说明
- **议事规则培训**：将议事规则纳入入职培训，确保新人理解公司协作决策方式

### 所属部门负责

- 部门职责与分工介绍
- 当前主要工作说明
- 新人的具体分工
- 需要接手的工作交接
- **笔试产出落地**：如通过笔试入职，将其工作蓝图或改写稿作为第一个工作起点，从方案落地开始进入工作节奏

### 第二大脑资料

- 使用第二大脑资料作为入职考核和学习材料
- 新人通过自学资料快速掌握标准，按标准干活
- 换人不换标准，换标准就统一改文本

## 适应期跟进

对应离职流程中的"答疑期"，确保新人入职后顺利过渡。

### 跟进安排

| 时间节点 | 跟进人 | 内容 |
|---------|-------|------|
| 入职第 3 天 | HR | 手续是否完成、环境是否就绪、有无困难 |
| 入职第 1 周 | 直属上级 | 工作方向是否清晰、团队融入情况 |
| 入职第 2 周 | HR + 直属上级 | 入职培训效果、是否需要调整安排 |

### 反馈收集

- 新人自评：入职流程是否有遗漏、哪些环节体验好/不好
- 上级反馈：新人上手速度、沟通协作情况
- HR 记录：跟进结果归档，作为流程迭代依据

## 试用期管理

### 阶段划分

| 阶段 | 时间跨度 | 目标 |
|------|---------|------|
| 熟悉期 | 第 1 周 | 了解业务全景、团队分工、工具链 |
| 上手期 | 第 2-3 周 | 在指导下完成具体任务，逐步独立 |
| 独立期 | 第 4 周起 | 独立承担工作，参与考核评估 |

### 各阶段关键动作

| 角色 | 动作 |
|------|------|
| **新人** | 按照阶段目标完成工作任务，主动提问和反馈 |
| **导师/上级** | 提供资源支持、示范操作、定期沟通进展 |
| **部门** | 准备必要的文档和交接材料，确保信息通畅 |

### 考核与反馈

- 每个阶段结束时进行一次评估，判断是否进入下一阶段
- 评估标准：能否按标准独立完成该阶段预期的工作
- 反馈机制：阶段末由导师/上级给出书面反馈，新人同步自评

### 流程迭代

- 如新人成长速度远超或远低于预期，复盘原因并调整培养方案
- 每季度回顾入职培养流程，沉淀可复用的经验

## 入职确认与归档

对应离职流程中的"交接确认"与"文件归档"。

### 入职确认

转正后，由 HR、直属上级、新人三方共同确认入职流程完成情况：

| 确认项 | 说明 | 确认人 |
|-------|------|-------|
| 入职材料 | 合同、证件、登记表是否齐全 | HR |
| 系统权限 | 工具账号、权限是否已开通 | HR |
| 培训记录 | 入职培训内容是否完成 | HR |
| 工作交接 | 分工安排、交接清单是否落实 | 直属上级 |
| 适应期评估 | 适应期跟进记录是否完整 | HR + 直属上级 |

确认无误后，由三方签署入职确认书，一式三份，三方各执一份。

### 文件归档

转正后一个月内，HR 将所有入职相关文件整理归档：

- 劳动合同
- 入职材料复印件/扫描件
- 入职培训记录
- 适应期跟进记录
- 试用期考核记录
- 入职确认书
