# 销售话术工作手册

## 使用说明

话术是参考模板，不是固定脚本。根据实际场景和个人风格调整。原则：**像真人说话，别像销售机器人。**

## 场景一：社交媒体首次触达

### 在评论区（公开）

```
太真实了，我去年也是这个状态……
后来试了一个方法，效率高了不少。
资料还在，有需要可以发你。
```

### 私信（一对一）

```
你好，看到你在学XX，我之前也走过这条路。
整理了一些学习资料和实战项目的经验，
如果你需要的话可以发给你参考一下。
```

## 场景二：需求确认

```
你现在主要卡在哪个环节？
学了多久了？遇到最大的困难是什么？
你希望学完后达到什么效果？
之前试过哪些学习方式？
```

## 场景三：价值展示

### 通用版

```
我们量潮课堂有个大数据实践课，
是用 ClickHouse 这些工业级工具做真实项目的。
浙江理工大学计算机系在用这个课，
学生跑完项目直接能写到简历上。
我觉得特别适合你现在想积累实战经验的需求。
```

### 针对转行者

```
你现在想转行大数据方向，这个判断是对的。
但面试官看你简历，最看重的不是你学了什么课，
而是你做了什么项目。
我们这个课就是让你有一个拿得出手的项目经验。
```

### 针对在校生

```
学校的课程偏理论，和企业需要的实战技能有差距。
我们的课是真实的企业项目流程，
你做完之后简历上会多一个完整的大数据项目。
```

## 场景四：异议处理

### "太贵了"

**先确认：预算不够还是觉得不值？**

> 「你方便说说大概的预算范围吗？我们也有不同的方案可以匹配。」

**如果预算不够：**

> 「理解了，那我们也有轻量版的课程方案，价格低一些但同样有项目实战。
> 你先看看合不合适，学完觉得有需要再升级。」

**如果觉得不值：**

> 「你担心的我能理解。要不你先试听一节内容，
> 看看质量是不是你想要的，再决定。」

### "我再想想"

> 「没问题，你主要是在犹豫哪个点呢？
> 是时间上不确定，还是担心课程效果？」

> 「要不这样，你先加一下我们学习群，看看其他同学的学习情况，
> 感受一下氛围再决定。」

### "没时间"

> 「你现在每周能抽出多少时间学习？
> 我们的课程是模块化的，可以碎片化学习，
> 每天30分钟到1小时就能跟上进度。」

### "我自己学也行"

> 「自学确实可以，但有两个问题：
> 一是不知道学什么方向是对的，
> 二是遇到问题没人指导容易卡住放弃。
> 我们的课有导师答疑和项目评审，
> 帮你少走很多弯路。」

## 场景五：促成转化

### 低门槛试水

```
要不你先体验一下课程内容，觉得合适再决定。
第一次课后如果不满意，可以全额退。
```

### 限时行动

```
本周有体验名额，如果你想试试可以帮你安排。
错过这周的话就要等下一期了。
```

### 直面顾虑

```
你现在还有什么顾虑吗？我们可以一起看看怎么解决。
如果暂时不报名也没关系，有问题随时问我。
```

## 场景六：跟进与服务

### 学中跟进

```
课程开始两天了，感觉怎么样？
有没有遇到什么问题需要帮忙？
```

### 结课反馈

```
恭喜学完课程！你觉得整个项目做下来最大的收获是什么？
如果方便的话可以写一段学习心得，帮到更多像你一样的人。
```

### 推荐邀请

```
如果你身边有朋友也在学大数据，可以推荐给我们。
推荐成功的话，你也会有一份感谢礼。
```

## 话术使用原则

1. **前30个字定生死**：开头要抓人，不要铺垫太长
2. **多用语气词**：啊、呢、哈、哭死——显得像真人
3. **不要一次性发大段文字**：分段发，给对方回应的时间
4. **每次沟通都要有"下一步"**：不让对话自然死亡
5. **没有回复就是回复**：3天没回复就放弃，不要追着问
