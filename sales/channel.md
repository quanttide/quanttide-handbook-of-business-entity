# 获客渠道工作手册

## 核心理念

获客不是广撒网，而是找到潜在客户聚集的地方，用他们能接受的方式出现。

## 渠道矩阵

| 渠道类型 | 具体渠道 | 适合场景 | 难度 |
|---------|---------|---------|------|
| 社交媒体 | 知乎、小红书、微博、抖音 | 内容引流，建立个人IP | 低 |
| 技术社群 | 微信群、QQ群、Discord、Telegram | 精准触达开发者群体 | 低 |
| 内容平台 | 公众号、博客、B站 | 长期沉淀，搜索流量 | 中 |
| 口碑推荐 | 学员推荐、朋友圈 | 信任度高，转化率高 | 低 |
| 线下活动 |  meetup、沙龙、校园宣讲 | 建立深度关系 | 高 |

## 社交媒体截流

### 帖子筛选——寻找"需求爆发点"

不要只看关键词，要看**用户动机**。

**痛点词：** "求助"、"避雷"、"求推荐"、"怎么考"、"急"

**情绪词：** "心态崩了"、"想哭"、"救命"、"只有我一个人觉得..."

**关联场景：**
- 教育类：期末考试、考研倒计时、论文查重
- 求职类：面试被挂、简历修改、大厂内推
- 生活类：装修踩雷、减肥瓶颈、独居好物

### 账号角色——建立"信任锚点"

根据业务目标选择人设：

- **过来人/学长学姐** — 教育、求职类。天然信任感，容易共鸣
- **行业专家** — 专业咨询类。权威背书，转化率高
- **同路人/踩坑者** — 生活消费类。接地气，互动性强

### 话术设计——从"共情"到"钩子"

话术遵循**"共鸣 + 价值 + 留白"**公式：

**共鸣（破冰）：**
> 「太真实了，我去年这个时候也快挂了……」
> 「这个方向确实坑，尤其是xx课……」

**价值（展示解法）：**
> 「后来我学长给我整理了一份思维导图，半天就过一遍了。」
> 「我当时也是换了这个思路，通过率才高起来的。」

**留白/钩子（引导私信）：**
> 「资料还在网盘，有需要可以发你。」
> 「这里的细节比较多，一两句说不清，你可以看我主页。」

## 技术社群获客

### 群选择标准

| 标准 | 说明 |
|------|------|
| 活跃度 | 每日消息量 > 50 条 |
| 人群匹配 | 成员以开发者、编程学习者为主 |
| 氛围 | 允许适度分享，非严格禁言群 |
| 群主关系 | 能与群主建立友好关系更佳 |

### 入群后操作

1. **先观察**：入群前3天只观察不说话，了解群规和讨论氛围
2. **再参与**：在别人提问时提供有价值的回答，建立专业形象
3. **后转化**：有人私信求助时，自然引导到课程

### 注意事项

- 不要在群里直接发广告链接（容易被踢）
- 不要批量加人私信（容易被举报）
- 先提供价值，再考虑转化

## 口碑推荐

### 推荐机制

学员学完后，邀请他们在朋友圈或技术社区分享学习心得。

**推荐话术：**

```
课程学完了，觉得收获怎么样？
如果方便的话可以发一条朋友圈分享一下，
这样能帮到更多像你一样的人。
推荐成功的话，你也会有一份感谢礼。
```

### 推荐激励

- 推荐朋友报名成功 → 推荐人获得课程优惠券或现金返现
- 学员产出优质学习心得 → 在官方渠道转发曝光

## 进阶技巧

### 评论区"排队"效应

在目标帖子的评论区，如果人设回复被赞到前几名，效果翻倍。利用小号在自己话术下留言"同求！"或"蹲一个解法"，营造"这个资源很抢手"的氛围。

### 个人主页"第二战场"

当用户被评论吸引进入主页时，**置顶帖子**或**瞬间/朋友圈**必须承接住：
- 主页要有清晰的**价值标签**
- 相册封面或背景图含蓄展示专业背书（证书、反馈截图等）

### 注意事项

- **不要在竞品的评论区硬刚**：容易投诉封号
- **软植入**：话术要像"真人"说话，多用语气词（啊、呢、哈、哭死），少用专业术语

## 获客检查清单

验收标准：目标渠道应匹配目标用户，账号角色应建立信任感，话术应遵循"共鸣+价值+留白"结构，主页"第二战场"应准备好承接流量，应避免竞品评论区硬刚。
