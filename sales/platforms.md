# 销售工具工作手册

## 客户跟进表

每位销售需维护自己的客户跟进表，推荐用飞书多维表格或 Excel。

### 表结构

| 字段 | 说明 | 示例 |
|------|------|------|
| 客户姓名 | 潜在用户姓名 | 张三 |
| 联系方式 | 微信/邮箱/手机 | wechat_id |
| 来源渠道 | 从哪找到的 | 知乎评论、技术群、朋友推荐 |
| 客户画像 | 身份+需求简述 | 转行求职，有Python基础 |
| 首次触达日期 | 第一次联系时间 | 2026-06-18 |
| 触达方式 | 评论/私信/邮件等 | 私信 |
| 沟通记录 | 每次沟通摘要 | 06-18: 发了资料，已读未回 |
| 当前阶段 | 流程中的位置 | 已触达、需求确认、价值展示、异议处理、已转化、已流失 |
| 预计转化日期 | 预估时间 | 2026-06-25 |
| 备注 | 其他信息 | 对价格敏感 |

### 使用规范

- 每天工作结束前更新跟进表
- 阶段变更时记录原因（如"已流失—预算不足"）
- 每周汇总数据：新增客户数、触达数、转化数、流失数

## CRM 操作说明

目前使用飞书多维表格作为简易 CRM。

### 基本操作

1. **新增客户**：在表格末行插入新记录，填写基本信息
2. **更新状态**：修改"当前阶段"字段，在"沟通记录"列追加本次沟通内容
3. **查询客户**：按姓名/来源/阶段筛选视图
4. **数据汇总**：使用表格的统计功能按阶段统计数量

### 状态流转示意

```
已触达 → 需求确认 → 价值展示 → 异议处理 → 已转化
                                    ↘ 已流失
```
