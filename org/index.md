# 组织管理工作手册

## 职权管理

### 基本原则

**下级统筹上级、上级治理下级、上下级共同协商。**

### 辅助性原则

如果下级请求上级给出判断，但上级给不出清晰的判断，下级独立临机判断决策、上级承担主要责任。

- **保障下级敢于犯错**：明确"即使联系中断也要按意图完成目标"
- **保障上级承担责任**：增加"如果因我意图不清导致你自行决策出错，责任在我"的硬性保障
- **传播模因**："公司你们说了算，我给你们背锅。"

### 新型组织契约

- **对上级**：你的权威不仅来自职位，更来自你在关键时刻提供清晰判断的能力。若不能，你必须用责任来为下属的能动性护航。
- **对下级**：你的能动性不仅是被授予的权利，更是在上级无法清晰指引时必须承担的义务。系统会为你提供责任保护。

### 职权分类

| 职权类型 | 说明 |
|---|---|
| 统筹权 | 决策权等 |
| 协商权 | 提案权等 |
| 治理权 | 审批权、审计权、澄清权等 |

职权的生命周期：产生 → 分配 → 使用 → 流转 → 消失

### 推广到一般场景

上下级关系本质上是一种委托代理关系。在任一委托代理关系中，当代理人基于信息优势提出行动请求，而委托人无法在约定时间内提供更优判断时，决策权自动转移给代理人，委托方承担主要风险责任。

> 设计者注：辅助性原则的本质是解决组织中的"决策瘫痪"。当上级给不出清晰判断时，让下级自行决策并给予责任保护——这既防止了因为等待而停滞，也倒逼上级提升决策质量。这是一种高级的信任机制：相信一线的人最了解情况，给予他们决策的权力，同时也要求他们承担决策的责任。

## 机制设计

工作机制设计是介于组织架构（静态）与临时项目协作（动态）之间的中观管理安排，核心目标是：在不频繁调整组织结构的前提下，通过明确角色、流程与协作规则，提升跨部门协同效率。

### 设计六步法

1. **界定机制边界与目标**：明确要解决的问题，划定参与主体范围
2. **识别关键角色与责任**：使用 RACI 矩阵（主责-配合-支持）
3. **设定协作规则与接口**：明确触发条件、沟通频率、决策层级
4. **保留灵活性与自组织空间**：避免过度中心化控制
5. **嵌入业务流程**：与现有业务流融合，避免平行流程
6. **定期回顾与迭代**：设定回顾周期，根据业务变化调整

好的工作机制设计 = **清晰的主责 + 最小的协调成本 + 最大的执行自主权**。

## 附录：组织管理检查清单

验收标准：辅助性原则应已传达给团队成员，上下级的职责边界应清晰，跨部门协作应有明确的机制设计，机制应有定期回顾和迭代的安排。

## 手册使用建议

1. 辅助性原则应作为组织的默认协作协议，而不是例外。
2. 机制设计从"最小必要协调"开始，避免过度设计。
3. 手册不替代章程：正式组织制度以章程为准。
