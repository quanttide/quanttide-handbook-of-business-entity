# 任务确认流程

实训任务从发布到承接确认的流程，产出《项目任务确认单》。任务的类型、描述、交付物、验收标准与计酬方式以确认单的记载为准（章程第八条、第十一条）。

## 角色

- 任务发布方（提供方）：发布任务并填齐任务要素；
- 承接学员：核对任务要素与计酬方式，决定是否承接。

## 流程

1. 任务发布：发布方按实训方向发布任务，写明任务描述与交付物；
2. 要素填写：发布方填齐任务类型、验收标准、计酬方式与冲回规则；
3. 费用核验：核对三项费用问题——本任务实训服务是否全部免费、是否须购课方可承接、报酬是否与购课或消费金额挂钩；三项以「否」为原则，出现「是」须附依据（独立课程服务协议编号、计价口径与依据）；
4. 知识产权确认：勾选归属方式——归提供方、双方共有、学员保留署名其余归提供方；
5. 承接确认：学员阅读并确认任务要素与计酬方式，确认后任务生效；
6. 执行与验收：学员按确认单执行，交付物按验收标准验收。

## 确认单要素

- 任务类型（可多选）：内容创作、客户推广、市场调研、活动执行、客服支持、技术协助、其他：____
- 任务描述 / 交付物：____
- 验收标准：____
- 计酬方式：固定津贴 __ 元 / 任务、按量 __ 元 / 件、提成 __%（按实际回款）、组合
- 退货 / 坏账冲回规则：____
- 本任务实训服务是否全部免费：是 / 否（说明：____）
- 是否须购课方可承接本任务：否 / 是（须附独立课程服务协议编号：____）
- 报酬是否与购课 / 消费金额挂钩：否 / 是（须列明计价口径与依据：____）
- 知识产权归属：归提供方 / 双方共有 / 学员保留署名其余归提供方
