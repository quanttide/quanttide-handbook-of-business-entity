# 激励规则流程

激励的评定与发放流程，依据《激励规则表》执行（章程第十条）。规则表可以独立更新版本，更新无需重签章程正文；当前版本：V____

## 角色

- 评定方（提供方）：核验触发条件、评定权益、发放激励；
- 学员：达成触发条件，自主选择是否领取、是否用于购课。

## 流程

1. 条件核验：按任务完成量、评级、业绩等触发条件核验学员达成情况；
2. 权益评定：对照规则表现行版本确定权益内容；
3. 发放：进阶课程优惠发放折扣或抵扣券；激励奖金达标即发，可自由支配；优先权益授予高阶实训与就业推荐顺位；实训积分入账；
4. 叠加规则：多项激励可以叠加；激励为额外奖励，不影响学员应得的实践报酬（章程第十条）；
5. 记录留痕：评定结论与发放记录留痕备查。

## 规则表

| 激励项 | 触发条件 | 权益内容 |
|:--|:--|:--|
| 进阶课程优惠 | 完成 N 个任务 / 评级达标 | 进阶课专享折扣或抵扣券 __ 元 |
| 实训激励奖金 | 月度业绩达标 | 奖金 __ 元，可自由支配或自愿购课 |
| 优先权益 | 综合表现前 __% | 优先高阶实训、优先就业推荐 |
| 实训积分 | 按任务 / 表现计分 | 积分兑换课程 / 活动 / 权益 |
