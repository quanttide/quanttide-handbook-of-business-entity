# 实训基地为中心的个性化学习服务

面向个人学习者的培养服务：以实训基地为载体，按人组织学习路径。与校企合作的班级授课不同，这里的每个学员带着自己的目标进来，通过做真实任务被培养。

## 服务形态

实训基地是培养的现场：学员在基地内以真实业务任务被培养（实训、实习），与量潮团队同场协作。

工作台是入口与考核的载体：报名、问卷、领任务、交付、评审、入册，全程在系统内完成（河床架构参考实现见实验室课堂工作台），流程脱胎于招聘考核，与之同构。

一对一定制：个案式教学服务，按学员目标定制教学计划，如氛围编程实训，以重构为中心、师生以同事身份探究。

## 学员资格

评估达标者由量潮出资培养——学员的真实工作产出对课堂有价值，这是免费的来源。资格通过评审授予（代表初审加负责人终审，结论留痕），授予后入册进入实训基地。付费开通为预留方向：与免费资格双轨，覆盖未达免费线的付费学习者，暂不实现。

## 培养机制

实践课与考核同构，实训任务标准化，以实际产出为准。生产实习即课程，学员自主选题、围绕企业真实需求，复用企业验收机制考核。每周有方法论课，由创始人讲最新方法论，包括技术选型、甲方思维、课题点评。激励政策上，产生实际价值的工作获得见习报酬，探索性尝试即使未达预期也记录在案，兑换导师专项指导。

## 经营定位

个性化学习服务是规模化收入的兑现端：校企合作输送生源与品牌，实训基地以免费资格筛选出可用之人，付费产品承接其余需求。「免费上课送实习」是课堂与招聘的连接点——实习与试用期匹配，完成即实训证明。
