# 付费学员培养流程

付费通道与免费学员资格双轨，覆盖未达免费线但愿意为培养付费的学习者。核心规则只有一条：付费学员与免费学员使用同一套考核标准，不因付费而降低要求——这是卖课模式的信誉基础。流程共四个环节。

## 报名

学员提交意向训练营与个人基本信息，姓名即进度凭证，全程唯一身份。

## 付费开通

按训练营定价付费，开通即入册。付费替代评审筛选作为准入机制，不占用免费额度，无需动机问卷。

## 一对一授课

付费培养的核心形态是一对一授课：按学员目标定制教学计划，导师与学员以同事身份围绕真实业务任务工作，以重构为中心，边做边学。节奏与内容随学员动态调整，与实训基地的群体任务互补。

## 交付与评审

学员按任务截止时间完成工作，提交交付物，留档备查。评审标准与免费学员一致，侧重参与度、思考的逻辑性与产出对公司的实际价值。评审通过即结业，产出达标者同样进入招聘通道。
