# 付费学员培养流程

付费通道与免费学员资格双轨，覆盖未达免费线但愿意为培养付费的学习者。与免费流程同构，核心规则只有一条：付费学员与免费学员使用同一套任务、交付与评审标准，不因付费而降低要求——这是卖课模式的信誉基础。流程共五个环节。

## 报名

学员提交意向训练营与个人基本信息，姓名即进度凭证，全程唯一身份。

## 付费开通

按训练营定价付费，开通即入册。付费替代评审筛选作为准入机制，不占用免费额度，无需动机问卷。

## 领任务

学员进入实训基地群，在任务清单中选定任务。任务与免费学员同源，来自量潮真实的业务工作。学员确认领到任务后标记进行中。

## 交付

学员按任务截止时间完成工作，提交交付物，留档备查。交付即进入评审队列。

## 评审

评审标准与免费学员一致，侧重参与度、思考的逻辑性与产出对公司的实际价值。评审通过即结业，产出达标者同样进入招聘通道。
