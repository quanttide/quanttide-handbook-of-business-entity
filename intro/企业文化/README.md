# 企业文化

# 灵感区

结合我们自己的经历，特别是创始人个人和团队的发展经历，阐述我们的初心是什么，我们希望达到的终极目标是什么样的。和大部分企业不同的是，要利用我们经济学家讲故事的能力进行直观清晰的设想。内部治理主要对应公司档案。

**使命（初心与出发点）​**

- **素材来源**​：“向死而生”的哲学；从抑郁和挫折中淬炼出的生存智慧；给市场“留下遗产”的终极目标。
- **商业计划阐述**​：我们的使命源于一个核心信念——​**通过直面终结来创造永恒价值**。我们不为短期的利润，而为解决真实的行业痛点，并为世界留下能持续产生积极影响的智慧与体系。

**愿景（终极目标）​**

- **素材来源**​：“被安然地遗忘”；打造“创业者生态”；“推翻大厦”后构建新系统。
- **商业计划阐述**​：我们的愿景是构建一个**能够自我进化、滋养创新的创业者生态系统**。我们的成功标准不是永远被铭记，而是我们创造的系统、文化和人才能够蓬勃发展，以至于我们的最初角色可以被安然地遗忘。

**文化内核**

- **素材来源**​：“懒惰是人类创新的源动力”；“向死而生”的坦然；对“压榨老板”文化的反思。
- **商业计划阐述**​：我们的文化鼓励 **​“务实的理想主义”​** 和 **​“建设性的懒惰”​** 。我们极度坦诚，直面问题，并通过制度化建设将人员波动的影响降到最低，从而**极大降低了组织维持卓越的“管理成本”​**​，构成了我们最深厚、最难复制的软性护城河。
