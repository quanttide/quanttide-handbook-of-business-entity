# 量潮科技手册

# 功能

企业内外理解整个公司运转机制的概括性手册。

旨在呈现一家有深刻思想、有宏大愿景、有独特治理哲学的企业，展示其如何共同构成一份强有力的叙事。

展示深刻的连贯性，​从宏观洞察到微观执行，从初心使命到治理文化，所有部分都由统一的世界观和方法论贯穿。

# 内容

本知识库计划包括几个方面：

1. 经营现状。这个部分大概是公司档案的简版，对于具体的业务怎么执行，这些并不介绍。但是会介绍一下整体经营状况，比如说今年的营收增长状况，需要介绍。
1. 战略体系。主要阐述高等教育、企业咨询、云计算三个具体业务的接力赛式发展方向。这里主要是要给投资人画饼到我们上市的时候会是一个怎么样的结构，这样的结构为什么具有足够深的护城河，和一般的厂商选择完全相反的路线相比有什么不同。内部治理主要对应战略档案。
1. 战术体系。阐述历史上的关键关系的成功失败，包括和厦大、腾讯云等微妙而复杂的关系，并且解释我们如何形成如今的战术风格。阐述接下来半年到一年的发展规划，比如启迪之星作为我们关键的合作伙伴会如何合作。也包括如何整合微专业等关键案例资源产生杠杆效应等。未来更新这些战术动作的时候，把规划作为复盘的一部分纳入考虑，并且不断更新新的战术动作。内部治理主要对应创业档案。
1. 经营体系。主要阐述我们自己的治理特色，比如民主和法治，并且阐述我们对这些治理规律的理解，阐述我们为什么需要这样的文化，在这样的文化下如何构建制度，阐述为什么这些治理特色帮助我们建立护城河，我们为什么维护这个护城河的成本更低。内部治理主要对应创新档案。分为创新。主要讨论标准化、信息化、数字化和智能化这四个方面。工程主要讨论我们各个功能工程体系的方向。管理主要讨论我们整个管理体系各个职能的功能和单元。商业化主要讨论我们怎么去获取市场，如何把非商业化业务商业化，如何进行规模化然后如何去获取市场。因为我们的特点是，管理和工程是并重的，甚至管理也是工程的一个部分。所以说呢，我们需要先讲完前面这些之后，然后再讲商业化这样比较符合高新科技公司重研发重管理的特点，然后在商业化部分讲怎么去获取市场，怎么去生产等等之类的，然后以及怎么把机制变成可以售卖的东西。我觉得从这个角度去讲，线索会更完整点，相比于单纯的讲增长。
1. 利益相关方。主要阐述我们希望我们的利益相关方如何参与。包括但是不限于员工、客户、供应商、合作伙伴、投资人等。讲对于各个利益相关方的要求，包括我们会选什么样的团队成员，然后我们需要什么样的资本方。然后，在资本方这一部分要去专门去讲，就是那我们打算怎么融资，融资过之后钱打算怎么花，然后我们希望能够达到什么样的效果等等之类。
